# SQL Contact Form Project

A simple Flask-based contact form project that stores user data using SQLite and sends submitted contact information to an email address.

## Features

- Contact form using HTML
- Backend built with Flask
- SQLite database integration
- Automatic email sending using Gmail SMTP
- Secure password handling using `.env`
- Git and GitHub integration

---

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- Gmail SMTP
